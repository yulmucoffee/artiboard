# Release

## 1. Before a build
- `shared/units.test.ts` passes, and each screen in `docs/screens.md` is checked in light and dark mode.
- `docs/api.md` matches the routes in `api/server.ts`.

## 2. Beta
Fifty households, invited by link. Each build says what changed since the last one; crashes and failed sign-ins are
read every morning.

## 3. Store listing
Screenshots come from the screens in `docs/screens.md`, in both palettes (`design/README.md`).
